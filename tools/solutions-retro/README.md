# Ретро-кейсы по истории PR

Как собирались кейсы `docs/solutions/` для PR, слитых до введения соглашения [SOLUTIONS.md](../../SOLUTIONS.md).

1. `export_dossier.py po-helper-org/<репо>` — досье слитых PR (запуск там, где есть `gh`).
2. Агент Hermes `po-doc-writer` по навыку [SKILL.md](SKILL.md) — задача на репо на доске PO-Harness:
   читает досье (и рабочую копию — только чтение), пишет кейсы, индекс и `retro-report.md`
   (каждый PR — кейс или пропуск с причиной).
3. `lint_solutions.py <OUT> <досье>` — формат, покрытие PR, обезличивание публичных репо.
4. Человек/Claude просматривает и открывает PR в репо.
